# Email Format Rules

## Structure

Every email must follow this layout order:

1. **Subject** — clear, specific, action-oriented
2. **Greeting** — personalized salutation
3. **Opening line** — context or purpose in one sentence
4. **Body** — details, structured logically
5. **Closing line** — next step or call to action (if applicable)
6. **Sign-off** — always `Best regards,` followed by sender name

## Templates

### Standard Professional Email

```
Subject: [Concise topic — verb + object preferred]

Hi [Name],

[Opening: one sentence stating purpose]

[Body: supporting details, max 3 paragraphs]

[Closing: next step or thank-you]

Best regards,
[Sender Name]
[Title, if applicable]
```

### Quick Notification

```
Subject: [Action item or status update]

Hi [Name],

[Direct message, 1–3 sentences]

Best regards,
[Sender Name]
```

### Email with Data or Results

```
Subject: [Report/Update: Topic]

Hi [Name],

[Opening sentence]

[Table or structured data — see → data-tables.md]

[Interpretation or next steps]

Best regards,
[Sender Name]
```

### Follow-up Email

```
Subject: Following up: [Original subject]

Hi [Name],

Following up on my previous message regarding [topic].

[Updated status or renewed ask]

Best regards,
[Sender Name]
```

## Greeting Rules

- Use `Hi [Name],` for professional but warm tone (default)
- Use `Dear [Name],` for formal contexts (legal, executive)
- Use `Hello [Name],` as neutral alternative
- Never use `Hey` in professional email
- If name is unknown, use `Hi there,`

## Sign-off Rules

- **Always** end with `Best regards,`
- Follow with sender name on the next line
- Optionally include title on the line after name
- Never omit the sign-off

## Subject Line Rules

- Max 60 characters
- Lead with a verb when action is expected: `Review:`, `Action required:`, `Update:`
- Avoid vague subjects: ~~`Important`~~, ~~`Hello`~~, ~~`FYI`~~
- Use sentence case, not title case for the full subject body
